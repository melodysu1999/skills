# QA Testing

QA Testing 是一套給 Codex 使用的 SIT 驗測流程。

只要提供一張 Mantis 問題編號或網址，它就能依照專案規則協助執行驗測、保存證據，並交付測試結果。

## 主要功能

- 每次驗測前讀取最新的 Mantis 需求、回話與附件。
- 確認正確的 SIT 環境、帳號角色及專案設定。
- 實際操作系統並保存測試證據。
- 中斷後從 checkpoint 安全續跑。
- 產生測試結果與 Mantis 私密回話。
- 選擇性產生一頁式 Word 測試報告。

## 使用方式

安裝外掛後，可以直接用自然語言提出需求，例如：

> 使用 QA Testing 驗測 Mantis 34199，保存證據並產生 Word 報告。

第一次使用時，系統會引導建立專案設定與測試規則。

## 安全原則

測試判定以實際 SIT 證據為準，不保存密碼，也不會自動修改 Mantis 狀態、指派人或刪除附件。

目前一次處理一張 Mantis 問題，適用於驗測、複測及驗證需求。
